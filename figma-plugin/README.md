# ปลั๊กอิน Figma: สร้างหน้าจอแจ้งซ่อม มช.

ปลั๊กอินนี้สร้างทุกหน้าของเว็บลงในไฟล์ Figma ของคุณ 2 ชุด พร้อมเส้น Interaction

| ชุด | เนื้อหา |
|---|---|
| **UI** | สีจริง ไอคอน และข้อความตามเว็บ |
| **Wireframe** | โครงสร้างสีเทา การ์ดมีเส้นขอบ รูปเป็นกล่องกากบาท |

แต่ละชุดมี 34 หน้า แบ่งเป็น 3 กลุ่ม (Section):

- **ผู้แจ้ง (มือถือ 390 × 844) 18 หน้า:** เข้าสู่ระบบ, ลืมรหัสผ่าน, ตั้งโปรไฟล์ + PDPA, หน้าแรก, แจ้งซ่อม 4 ขั้น, เจอคำร้องซ้ำ, ส่งสำเร็จ, ติดตามสถานะ (รอรับเรื่อง / ซ่อมเสร็จ), ยกเลิก, ให้คะแนน, ยังไม่หาย, ประวัติ, แจ้งเตือน, โปรไฟล์
- **ช่าง (มือถือ) 8 หน้า:** งานของฉัน, รายละเอียดงาน 3 สถานะ (มอบหมายแล้ว / กำลังซ่อม / รออะไหล่), พักงานรออะไหล่, บันทึกงานซ่อมเสร็จ, แจ้งเตือน, โปรไฟล์
- **ผู้ดูแลระบบ (เดสก์ท็อป 1440 × 900) 8 หน้า:** แดชบอร์ด, คำร้องทั้งหมด, แผงจัดการคำร้อง (รอรับเรื่อง / รับเรื่องแล้ว), มอบหมายช่าง, ข้อมูลพื้นฐาน 3 แท็บ

## ติดตั้ง (ครั้งเดียว)

ต้องใช้ **Figma Desktop App** เพราะเวอร์ชันเว็บนำเข้าปลั๊กอินจากไฟล์ไม่ได้

1. เปิดไฟล์ Figma ที่ต้องการ (แนะนำไฟล์ใหม่)
2. เมนู **Plugins → Development → Import plugin from manifest…**
3. เลือกไฟล์ `figma-plugin/manifest.json` ในโฟลเดอร์โปรเจกต์นี้

## ใช้งาน

1. **Plugins → Development → Smart CMU Maintenance — Screens**
2. เลือกชุดที่ต้องการ (UI / Wireframe) และติ๊ก **โยงเส้น Interaction**
3. กด **สร้างทุกหน้า** แล้วรอประมาณ 10–30 วินาที

ปลั๊กอินจะสร้าง 2 หน้าในไฟล์ (Page): `UI — แจ้งซ่อม มช.` และ `Wireframe — แจ้งซ่อม มช.` ถ้าติ๊ก "แทนที่หน้าเดิม" การรันซ้ำจะลบ 2 หน้านี้แล้วสร้างใหม่ ส่วนหน้าอื่นในไฟล์ไม่ถูกแตะ

## ดูเส้น Interaction

1. เปิดแท็บ **Prototype** ทางขวา จะเห็นเส้นโยงจากปุ่มไปหน้าถัดไป
2. กด ▶ **Present** แล้วเลือก Flow จากเมนูซ้าย มี 3 Flow:
   - **1 · ผู้แจ้ง:** เข้าสู่ระบบ → แจ้งซ่อม → ติดตาม
   - **2 · ช่าง:** รับงาน → ส่งงาน
   - **3 · ผู้ดูแลระบบ:** รับเรื่อง → มอบหมายช่าง

แต่ละชุดมีเส้นโยง 161 เส้น เช่น ปุ่ม แถวรายการ แถบเมนูล่าง เมนูด้านข้าง ปุ่มย้อนกลับ และปุ่มปิดหน้าต่าง

## ฟอนต์

ปลั๊กอินเลือกฟอนต์ภาษาไทยที่มีในเครื่องตามลำดับ: `LINE Seed Sans TH` → `IBM Plex Sans Thai` → `Noto Sans Thai` ปกติ Figma มี IBM Plex Sans Thai ให้อยู่แล้ว ถ้าไม่มีฟอนต์ไทยเลย ปลั๊กอินจะแจ้งเตือนหลังสร้างเสร็จ

## แก้ไขหน้าจอ

หน้าจอทั้งหมดอยู่ใน `code.js` แยกเป็นฟังก์ชันต่อหน้า เช่น `R03()` คือหน้าแรกของผู้แจ้ง `T02` คือรายละเอียดงานของช่าง และ `A01()` คือแดชบอร์ด เส้น Interaction ประกาศด้วย `to: "รหัสหน้า"` ในปุ่ม หรือด้วย `link(node, "รหัสหน้า")` แก้แล้วรันปลั๊กอินใหม่ได้เลย ไม่ต้อง build
