# รายงาน สไลด์ และแผนภาพ

โฟลเดอร์นี้สร้างเอกสารส่งงานตามเกณฑ์การประเมินจากโค้ด แก้ข้อความหรือแผนภาพแล้วสั่งสร้างใหม่ได้ทันที

## ไฟล์ที่ได้ (`out/`)

| ไฟล์ | เนื้อหา |
|---|---|
| `รายงาน-ระบบแจ้งซ่อม-มช.docx` | รายงานฉบับเต็ม 8 บท พร้อมบรรณานุกรมและภาคผนวก (มีไฟล์ `.pdf` คู่กัน) |
| `สไลด์-ระบบแจ้งซ่อม-มช.pptx` | สไลด์นำเสนอ 17 หน้า (มีไฟล์ `.pdf` คู่กัน) |
| `diagrams/*.png` / `*.svg` | ภาพแผนภาพทุกแผนภาพ |
| `diagrams/*.drawio` | แผนภาพที่เปิดแก้ใน draw.io ได้ ดับเบิลคลิกแผนภาพ → Edit เพื่อแก้โค้ด PlantUML แล้ว draw.io วาดใหม่ให้ |

## แผนภาพ (`diagrams/*.puml`)

| ไฟล์ | แผนภาพ |
|---|---|
| `01-usecase.puml` | ยูสเคส (4 ผู้กระทำ 27 ยูสเคส) |
| `02-activity-submit.puml` | กิจกรรม: แจ้งซ่อม |
| `03-activity-admin.puml` | กิจกรรม: คัดกรองและมอบหมายช่าง |
| `04-activity-technician.puml` | กิจกรรม: งานซ่อมของช่าง |
| `05-activity-confirm.puml` | กิจกรรม: ติดตามสถานะและยืนยันผล |
| `06-state.puml` | สถานะของคำร้อง (ตรงกับ `lib/requests/transition.ts`) |
| `07-ia.puml` | สถาปัตยกรรมสารสนเทศ (แผนผังเว็บไซต์) |
| `08-userflow.puml` | ผังการใช้งาน |
| `09-activity-dashboard.puml` | กิจกรรม: แดชบอร์ดและส่งออกรายงาน (ฟังก์ชันเพิ่มเติม) |

สีและฟอนต์ที่ใช้ร่วมกันอยู่ใน `_style.iuml` แก้ออนไลน์ได้ที่ plantuml.com หรือส่วนขยาย PlantUML ใน VS Code

## สร้างใหม่

ต้องมี Node.js และ Java 17 ขึ้นไป ครั้งแรกให้ติดตั้งแพ็กเกจและดาวน์โหลด `plantuml.jar` ไปไว้ใน `tools/`

```bash
npm install
```

```bash
npm run all
```

`npm run all` จะสร้างแผนภาพ รายงาน และสไลด์ตามลำดับ ถ้าต้องการสารบัญที่มีเลขหน้าและไฟล์ PDF ให้เปิดไฟล์ผ่าน Microsoft Word ด้วยสคริปต์นี้ (Windows)

```bash
powershell -ExecutionPolicy Bypass -File tools/word-finalize.ps1 "out/รายงาน-ระบบแจ้งซ่อม-มช.docx"
```

## หมายเหตุการจัดรูปแบบรายงาน

- ฟอนต์ TH SarabunPSK 16 พอยต์ หัวข้อบท 20 พอยต์ หัวข้อย่อย 18 พอยต์
- ระยะขอบ บนและซ้าย 1.5 นิ้ว ล่างและขวา 1 นิ้ว ย่อหน้า 0.5 นิ้ว จัดแนวกระจายแบบไทย
- ชื่อตารางอยู่เหนือตาราง ชื่อภาพอยู่ใต้ภาพ ลำดับเลขตามบท (ตารางที่ 2.1, ภาพที่ 5.3)
- เลขหน้าส่วนหน้าเป็นตัวอักษรไทย (ก ข ค) เนื้อหาเริ่มหน้า 1
- Word บางเครื่องตัดคำภาษาไทยไม่ได้ สคริปต์จึงแทรกตัวแบ่งคำที่มองไม่เห็นไว้ทุกคำ ถ้าพบคำที่ถูกตัดกลางคำ ให้เพิ่มคำนั้นใน `lib/thai-words.js`
- **หน้าปกยังเว้นชื่อผู้จัดทำ รหัสนักศึกษา และชื่ออาจารย์ไว้** กรอกใน `build-report.js` (ส่วน Cover) หรือแก้ใน Word โดยตรง

ภาพหน้าจอใน `screens/` สร้างจากปลั๊กอิน Figma ด้วย `tools/shots.js`
